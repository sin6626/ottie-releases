# Ottie for Android

Ottie is a sea otter that watches your subscriptions. This repo only hosts the Android APK. Get it and learn more at https://ottie.pages.dev

Every version is under [Releases](https://github.com/sin6626/ottie-releases/releases), with the file `Ottie.apk`. Each release note is in English first, with Chinese below.

## 中文

Ottie 是一只帮你盯订阅的海獭。这里只放安卓安装包，下载请去官网：https://ottie.pages.dev

每个版本在 [Releases](https://github.com/sin6626/ottie-releases/releases) 里，附件 `Ottie.apk`。每个版本的说明先写英文，中文在下面。
